About This Page

This page demonstrates how to embed the Marketinside chatbot widget into any website. The widget appears as a floating button in the bottom-right corner.

Features Demonstrated

  • ✅ Automatic URL detection and tracking
  • ✅ Session persistence across page navigations
  • ✅ Dynamic content based on current page
  • ✅ Responsive design that works on all devices
  • ✅ SPA (Single Page Application) support with URL change detection

How It Works

The chatbot widget automatically:

  1. Detects the current page URL and sends it to the backend
  2. Generates a unique session ID for the user
  3. Maintains chat history across page navigations
  4. Monitors URL changes (for SPAs) and updates context

  • The widget uses localStorage for session persistence
  • Cross-origin requests must be enabled on the backend (CORS)
